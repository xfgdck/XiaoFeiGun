### 主要特性
**免配置**：已内嵌高效配置，无需手动设置，开箱即用。  
**多线程**：利用 aria2 的多连接机制，自动提升下载速度。  
**高并发**：同时处理多个下载任务，互不影响。  
**网络代理**：复杂网络环境下依然保持高速稳定连接。  
**自动更新 BT Tracker**：保持最新 tracker 列表，提高 BT/Magnet 任务连接效率。
